# Assets do portfólio

Esta pasta preserva no GitHub os arquivos visuais usados na criação do portfólio.

- `instagram/`: artes dos posts e imagens de rotina profissional.
- `references/portrait.webp`: retrato original usado como referência visual.
- `references/portfolio-reference.png`: referência de identidade visual enviada para o design.

As credenciais e variáveis privadas do Supabase não são versionadas. Elas devem permanecer configuradas no ambiente seguro do projeto.
